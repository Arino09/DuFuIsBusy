# 绘画点评循环验证

工具链：Godot 4.7.2 stable `ed1daf0bf`，同版本官方 Web 模板；Chromium 151 / Playwright。本轮只修改 DuFuIsBusy，未触碰 GameJam2026。

## 验证范围

- Godot 真实像素测试 `tests/drawing_test.gd`：初始空白、空擦无历史、无效起点、连续绘制、真实擦空、撤销恢复原始字节、重做、边界终止、节点重建状态、实际合成图片尺寸、20 步上限、新笔画清空重做。
- Chromium 实际 WebGL，路径 `/DuFuIsBusy/`：五页导航、选命题、颜色/笔宽、鼠标绘画、空白/擦空提交拒绝、撤销重做、实际合成图片与本地点评、重复提交不改变提交版本、各命题独立保留。
- 触摸通过 Chrome DevTools 原生触摸事件发送，断言笔画历史增加。不是仅调用绘画函数。
- 越界后按住返回不续线；浏览器 blur 结束笔画，失焦后移动不续线；缩放结束笔画；1024×768 缩放后继续绘画与提交。另检查 844×390、390×844 截图。
- 恢复创作取消/确认；中文字体子集；全部资源请求、浏览器控制台与脚本错误。

首轮强化测试发现 Web blur 未触发 Godot 窗口失焦信号；已用 JavaScriptBridge 注册窗口 blur 与文档 visibilitychange，回调仅结束笔画。不会联网或改变系统安全设置。窗口尺寸变化也结束笔画。事件监听随根节点释放清理。

本地浏览器沿用此任务已明确授权的隔离 localhost 测试例外，只允许 127.0.0.1 请求，临时上下文，结束关闭。测试脚本默认启用沙箱；只有明确授权时可通过环境变量设置局部例外。

## 限制

- 所有画卷与历史只在本次运行保留。刷新或关闭会丢失；UI 明示。设置偏好仍使用本机持久化。
- 点评为预写趣味文案，只判断剩余笔迹非空，不识别命题完成度。
- 作品文件保存、导出、永久画廊、贴纸与文字编辑未实现。人物原图不受橡皮影响。
- 竖屏采用等比缩放，控件较小，没有独立手机布局。自动触摸验证不等于真机触屏测试。
- 本轮重试公开 Pages 域名仍收到代理 CONNECT 403；CI 部署成功与线上截图验证分开报告，不将本地截图当线上截图。

截图在 `docs/screenshots/`，本轮机器证据在 `docs/drawing-qa.json`。原 UI 阶段的 `docs/browser-qa.json` 属于历史记录，不代表当前功能覆盖。

最终结果：Godot 像素测试通过，Web 全量 17 张截图与最终布局 5 张截图检查通过。无浏览器异常、控制台错误、失败资源请求或外部请求；软件渲染截图仅产生 ReadPixels 性能提示。两次浏览器均已关闭。全部脚本非 ASCII 字符在双字体子集中均有字形。
