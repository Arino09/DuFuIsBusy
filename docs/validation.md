# 本地保存阶段验证

工具链保持 Godot 4.7.2 stable `ed1daf0bf`、同版官方 Web 模板和 Chromium 151。只修改 DuFuIsBusy；未修改旧 GameJam2026、凭据或系统安全设置。

## 数据与功能

- `tests/storage_test.gd`：完整状态 JSON 往返，透明笔迹像素逐字节一致；中文、颜色、字号、对象 ID/位置/缩放/旋转、提交状态与作品关联均恢复；无效结构拒绝；快照独立；历史按设计不跨刷新。
- `tests/drawing_test.gd`：原有笔迹、真实擦除、混合对象历史与边界测试继续通过。
- `tests/browser_storage.py`：真实 WebGL、`/DuFuIsBusy/` 子路径；即时刷新后恢复完整草稿，再关闭整个 Chromium 进程，用同一持久配置重开并核对可编辑数据。
- 画廊明确保存、连续重复点击及未修改再次保存不重复；重新打开编辑可修改中文；修改后的保存成为新版本，原作逐字段保持不变；另存新作及多个命题草稿并存。
- 真实浏览器 PNG 下载完成，图片为 1040×330；下载文件与保存的完整合成 PNG 字节完全一致，不是界面截图。
- 保留示例画廊；实际检查我的画廊、保存确认、重新打开、异常提示与作品预览截图。

## 存储失败

- 使用临时浏览器配置实际填满 localStorage 配额，验证新草稿和明确保存失败时原存档不变，不出现保存成功或新增作品条目。清除测试占位数据后，重试成功。
- 对该临时页面注入 Storage 读取的 SecurityError，验证不可用提示、原值保护及恢复权限后重试；原草稿和作品均保留，并可再次进入编辑。
- 模拟其他标签页修改存档，确认检测到冲突后不覆盖；写入损坏测试数据后，确认解析失败保护原值、不自动重置存档。
- JSON 解析用返回错误码的 API，损坏存档不会造成未处理脚本错误。

浏览器测试只访问 localhost，沿用该任务此前授权的隔离临时浏览器例外。故障注入只发生在测试页面，真实配额测试不改变浏览器配额或系统安全设置。测试后关闭浏览器并移除临时配置。

## 范围与限制

- Web 存档仅属于同一浏览器配置和站点，不跨设备；清理站点数据、无痕结束或浏览器回收数据可能丢失。
- 每个命题保留一份草稿。打开旧作前确认替换当前命题草稿，画廊旧作不变。
- 撤销/重做历史、未点击应用的文字输入弹窗不跨重开保存。PNG 是合成图，不是可编辑工程备份。
- 不承诺固定配额或无限作品数量；暂无应用内作品删除、云同步或可编辑工程文件导出。
- 原生文件后端有错误处理，但持久性专项以 Web 为验收目标；未新增原生平台重启验收，也未进行真机移动浏览器下载测试。
- 本地截图不是线上截图。当前环境此前访问公开 Pages 的代理返回 CONNECT 403；部署结果与线上访问验证分开报告。

本阶段证据为 `docs/storage-qa.json`、`docs/screenshots/` 与其中的 `exported-artwork.png`。`tools-qa.json` 等历史记录保留供对照。数据说明见 [storage.md](storage.md)。

最终结果：Godot 两组测试及三组 Web 浏览器测试通过，无未处理脚本错误、控制台错误或失败资源请求。截图仅有软件 WebGL 的 ReadPixels 性能提示。全部测试浏览器已关闭；中文字体覆盖当前 UI 文案。
