# 本地草稿、画廊与 PNG

Web 使用同源 localStorage 的独立键 `DuFuIsBusy.art.v1`，不会访问或修改旧 GameJam2026 项目的键。同步 `setItem` 完成后才报告保存成功，不依赖 Godot Web 文件系统的异步 IDBFS 同步。无需账号、网络接口、后端或凭据。

## 数据

- `version`：结构版本；当前为 1，不能识别的版本会停止写入并保护原数据。
- `drafts`：四命题与自由创作各一份可编辑草稿，保存 PNG 编码的透明笔迹像素、对象种类/ID/位置/比例/旋转、文字/字号/颜色、修订号、已点评版本及关联作品 ID。
- `works`：明确保存的完整作品，含上述图层数据、命题、独立 ID、标题和完整合成 PNG。修改后另存新版本，旧记录不变。未修改时重复保存复用条目。
- 当前页面、命题、画笔颜色、笔宽与工具一并恢复。选择框、临时输入弹窗和撤销历史不持久化。

画廊重开某幅作品前会确认替换该命题的当前草稿。其他命题草稿及画廊旧作不受影响。只在内存中编辑不会改动已完成作品，必须明确保存。

## 失败处理

整份 JSON 一次写入；写入抛出配额或权限错误时，不更新内存中的已保存作品目录，不分配已保存 ID，不显示成功。已有浏览器值保持不变；当前画面仍可编辑、点评和下载 PNG。错误在页面底部和明确保存的弹窗中显示。

每次写入前比较此前读取的原值，若检测到其他标签页修改则拒绝覆盖并提示刷新。此检查用于避免常见的陈旧标签页覆盖，不声称提供多标签页数据库事务。解析异常会停止写入，保留原始值。原生 Godot 使用同项目 `user://art-v1.json`，先写临时文件并检查结果，再改名。

容量由浏览器决定，不承诺固定作品数量或永久保存。此版本不提供云备份、可编辑工程文件导入导出、画廊删除或跨浏览器同步。下载 PNG 只是图像备份，不能恢复为可编辑对象。无痕模式结束、清理站点数据或浏览器回收数据后，本地存档可能丢失。

## 下载

PNG 为同一画布渲染器在 SubViewport 中合成的 1040×330 图片，包含人物、笔迹、文字和贴纸，不含控件、选框或点评文案。Web 由用户点击触发 `JavaScriptBridge.download_buffer`；界面不声称文件已写入用户磁盘，最终下载由浏览器处理。
